# Oasis Infobyte Python Internship Projects

Welcome to my Python Development Internship portfolio! This repository contains a collection of projects I developed as part of the **Oasis Infobyte Internship Program (OIBSIP)**.

## Projects Overview
Each folder in this repository represents a specific task I completed during the internship:

1. **[BMI Calculator](Python-Task2-BMICalculator/):** A tool to measure Body Mass Index and track health data.
2. **[Password Generator](Python-Task3-PasswordGenerator/):** A secure utility to create randomized, strong passwords.
3. **[Weather App](Python-Task4-WeatherApp/):** An application that provides real-time weather updates using APIs.
4. **[Chat Application](Python-Task5-ChatApplication/):** A real-time messaging system built with Python, featuring a GUI and socket-based communication.

## About The Internship
This program focused on honing my skills in:
- Core Python Programming
- GUI Development (Tkinter)
- API Integration
- Socket Programming and Networking
